# Alloy

![Alloy Logo](assets/alloy.png)

Alloy explores extreme model–hardware co-design for LLM inference on FPGAs.

The goal is to optimize the model, compute architecture, memory system, dataflow, precision, and RTL implementation as one system.

I’m starting with autoregressive decoding on a Nexys A7-100T FPGA, pushing toward a highly specialized end-to-end implementation.
